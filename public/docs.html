📘 Documentation de l’API – Port Russell

Bienvenue dans la documentation officielle de l’API du port de plaisance Port Russell.

⬅ Retour à l’accueil

🔐 Authentification

POST /users/register

Créer un utilisateur.

POST /users/login

Connexion, renvoie un token JWT.

{
  "email": "test@test.com",
  "password": "123456"
}

👤 Users

GET /users

Liste des utilisateurs (admin).

GET /users/me

Retourne le profil du user connecté.

DELETE /users/:id

Supprime un utilisateur.

⚓ Catways

GET /catways

Liste des catways.

GET /catways/:id

Détails d’un catway.

POST /catways

Créer un catway.

PUT /catways/:id

Modifier un catway.

DELETE /catways/:id

Supprimer un catway.

📅 Reservations

GET /reservations

Liste générale (pagination, tri, filtres).

GET /reservations/my-reservations

Réservations du user connecté.

GET /reservations/catway/:catwayId

Réservations d’un catway.

GET /reservations/period?from=YYYY-MM-DD&to=YYYY-MM-DD

Réservations dans une période.

GET /reservations/active

Réservations actives aujourd’hui.

GET /reservations/upcoming

Réservations futures.

GET /reservations/past

Réservations passées.

GET /reservations/stats

Statistiques globales.

POST /reservations

Créer une réservation.

PUT /reservations/:id

Modifier une réservation.

DELETE /reservations/:id

Supprimer une réservation.

🔑 Header d’authentification

Toutes les routes protégées nécessitent :

Authorization: Bearer VOTRE_TOKEN
