📘 Documentation de l’API – Port Russell

Documentation officielle de l’API réellement implémentée dans votre projet.

⬅ Retour à l’accueil

🔐 Authentification

POST /users/login

Connexion utilisateur. Retourne un token.

{
  "email": "test@test.com",
  "password": "123456"
}

POST /users/register

Créer un utilisateur (si route activée dans votre backend).

🔑 Header requis pour toutes les routes protégées

Authorization: Bearer VOTRE_TOKEN

👤 Utilisateurs

GET /users/me

Retourne le profil de l’utilisateur connecté.

GET /users

Liste tous les utilisateurs (si autorisé).

DELETE /users/:id

Supprime un utilisateur.

⚓ Catways

GET /catways

Liste tous les catways.

GET /catways/:id

Retourne les détails d’un catway.

POST /catways

Créer un catway.

PUT /catways/:id

Modifier un catway.

DELETE /catways/:id

Supprimer un catway.

GET /catways/:id/reservations

Liste les réservations associées à un catway.

📅 Réservations

GET /reservations

Liste toutes les réservations.

GET /reservations/:id

Retourne une réservation spécifique.

POST /reservations

Créer une réservation.

PUT /reservations/:id

Modifier une réservation.

DELETE /reservations/:id

Supprimer une réservation.
